# dice

ボタンを押すと 1〜6 の目がランダムに出る、シンプルなサイコロです。HTML 1ファイルで完結しています。

**公開ページ:** https://re7a4na10.github.io/dice/

## 使い方

1. 上の公開ページを開く（またはローカルで `index.html` をブラウザで開く）
2. 「サイコロを振る」ボタンを押す

インストールやビルドは不要です。

## 特徴

- 1〜6 の目を 3×3 のマス上に点（ピップ）で表示
- 1 の目は本物のサイコロのように大きな赤い点で表示
- 振るたびに回転するアニメーション付き
- 外部ライブラリなし（HTML / CSS / JavaScript のみ）

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | サイコロ本体 |
| `プロンプトに打ち込む文章.txt` | このサイコロを生成したときのプロンプト |

## GitHub Pages での公開

1. リポジトリの **Settings → Pages** を開く
2. **Source** で「Deploy from a branch」を選ぶ
3. **Branch** で `main`、フォルダで `/ (root)` を選んで **Save** を押す

`main` に push すると、数十秒〜数分で公開ページに反映されます。
